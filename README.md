Global Covid-19 Data Analysis Dashboard (Power BI)
This repository features an interactive Power BI dashboard for comprehensive analysis of the global Covid-19 pandemic dataset. The dashboard provides critical insights on the worldwide spread, recovery, and impact of Covid-19 cases using visually engaging charts and maps.

Dashboard Features
Global Summary KPIs:
Instantly view total confirmed cases, active cases, recoveries, and deaths at the top of the dashboard.

Monthly & Regional Trends:
Analyze total deaths by month, and track total confirmed and recovered cases by WHO region.

Country-Wise Analysis:
Interactive donut chart and tables show the percentage of deaths by country, with granular data on each nation.

Geospatial Visualization:
Global map displays pandemic hotspots and spread across continents.

Dynamic Filtering:
Filters for months, country/region, and WHO region allow users to drill down and explore specific trends and areas of interest.

Key Visualizations
Card KPIs for total confirmed, recovered, active cases, and deaths

Donut & bar charts for country-wise and region-wise breakdown

Line charts for monthly death trends

Interactive map visualization of global Covid-19 cases

How to Use
Open the Power BI dashboard file (.pbix) in Microsoft Power BI Desktop.

Use slicers on the left to filter data by month, region, or country.

Interact with any visualization to see detailed, real-time breakdowns.

Data Sources
The dashboard is based on the most recent global Covid-19 datasets, including case counts and summary statistics reported by WHO and health agencies.
